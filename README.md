# pico-circuitpython-block-builder

Raspberry Pi Pico の CircuitPython 用 `code.py` を、ブロックを並べて作るツールです。
HTML ファイル 1 個だけでできているので、インストールもビルドも要りません。

https://mtjwtjmuj.github.io/pico-circuitpython-block-builder

![画面](/screenshot.png)

## つかいかた

上の URL を開いて、

1. 「部品」タブから使うものを選ぶ
2. 選んだ部品用のブロックが「動作」タブに増えるので、それを並べる
3. 右上の code.py を押してダウンロード
4. Pico を USB でつなぐと出てくる `CIRCUITPY` ドライブの、一番上の階層に置く

ファイルを置いた時点で Pico が動き出します。

CircuitPython がまだ入っていない Pico なら、先に [circuitpython.org](https://circuitpython.org/board/raspberry_pi_pico/) から uf2 を落として、BOOTSEL を押しながら挿した Pico にドラッグしてください。
OLED や BME280 など、ライブラリが必要な部品を使った場合は「準備」タブに必要なファイル名が出ます。

## なぜ作ったか

Pico で電子工作を始めた人がつまずくとき、原因がコードなのか配線なのか本人にも分からない、というのをよく見ます。
それなら、ブロックを並べて組んだものと、そこから出てくる Python と、その部品の配線手順を、全部同じ画面に並べてしまえばいいだろう、というのが出発点です。

ブロックで Pico を触れるものは BIPES や Piper Make など既にありますが、どれも MicroPython が前提でした。
Adafruit のライブラリを使いたい場面が多いので、CircuitPython の `code.py` をそのまま吐くものが欲しかった、という事情もあります。

## できること

部品は 27 種類あります。追加すると、その部品を動かすためのブロックだけがパレットに出てくるので、「何が使えるのか分からない」状態になりにくいはずです。
くり返し、条件分岐、変数もあるので、押した回数を数えるとか、暗くなったら点けるといったものは組めます。

ピンは部品を追加した順に空いているところへ自動で割り当てます。
自分で変えたときに重複したり、アナログ入力でないピンに可変抵抗を割り当てたりすると、その場で指摘します。

もう少し踏み込んだチェックも入れてあります。
部品名や変数名に `time` や `while` を付けると Python 側の名前とぶつかって実行時に落ちるので、これは自動で直します。
I2C の SDA と SCL を入れ替えて設定した場合のように、コードとしては書けてしまうが Pico の上では例外になる組み合わせは、直すまで code.py を書き出せないようにしてあります。

作りかけのものは JSON で保存して、あとから読み込めます。
サンプルも 10 個入れてあるので、まず読み込んで中身を眺めるのが早いと思います。

生成されるコードは CircuitPython 9 以降の書き方（`i2cdisplaybus.I2CDisplayBus`、`display.root_group` など）に合わせています。

## 対応している部品

| | |
|---|---|
| 出力 | 内蔵LED、LED（PWM可）、フルカラーLED、NeoPixel、ブザー、サーボ、DCモーター、リレー、デジタル出力 |
| 表示 | OLED (SSD1306)、キャラクタLCD |
| 入力 | ボタン、タッチ、可変抵抗、光センサー、アナログ入力、デジタル入力、人感センサー、内蔵温度、DHT11/22、HC-SR04、BME280、MPU6050、ロータリーエンコーダ |
| 通信 | USBキーボード (HID)、USBマウス (HID)、UART |

Pico W / Pico 2 でも、上の部品を使う範囲なら同じように動きます。無線まわりのブロックはまだありません。

## 動作環境

Chrome、Edge、Firefox、Safari で確認しています。スマートフォンでも一通り操作できます。
外部ライブラリも CDN も使っていないので、HTML を保存しておけばオフラインでも動きます。

## 中身について

単一 HTML、素の JavaScript のみ、依存関係なしです。

部品のカタログ（`PARTS`）とブロックのカタログ（`BLOCKS`）を分けてあり、部品を 1 つ足すとパレット・配線ガイド・ピン配置図・コード生成のすべてに反映されます。部品を追加したい場合はここだけ触れば済むはずです。

生成した Python は、全サンプルと全部品・全ブロックの組み合わせ 44 パターンについて `ast.parse` で構文チェックを通してあります。
